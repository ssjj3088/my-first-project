청도 다문화캠프 카드뉴스

여행 포스터 콜라주 스타일, 인스타그램·페이스북 광고용 4:5 캐러셀 5장. 관광지 사진을 넣고 신청 정보를 채운 뒤 PNG로 만드세요.

언어

한국어 디자인을 확정한 뒤 영어·중국어·베트남어·태국어 버전을 같은 디자인으로 만듭니다.

행사 정보

주황색 칸은 아직 기본값입니다. 광고 올리기 전에 꼭 바꿔주세요.

관광지 사진

사진이 없으면 일러스트가 들어갑니다. 출처 칸은 공공누리 표기용이며 사진 모서리에 작게 표시됩니다.

유료광고 운영 가이드

1. 언어는 카드 한 장에 섞지 말고, 언어별로 한 세트씩

  • 5개 언어를 한 장에 넣으면 글씨가 작아지고, 누구에게도 "내 얘기"로 안 읽힙니다.
  • 그래서 언어마다 5장 세트를 따로 만들고, 그 언어를 크게 + 한국어를 작게 넣었습니다. 한국인 배우자와 함께 보기에도 좋습니다.
  • Meta 광고관리자의 광고 단계에서 언어 추가를 켜고 기본은 한국어, 추가로 영어·중국어·베트남어·태국어 세트와 문구를 넣으면 사용자의 앱 언어에 맞는 버전이 자동으로 나갑니다.
  • 언어별 성과를 따로 보고 싶다면 광고세트를 언어별로 나누고 타게팅의 언어 항목을 각각 지정하세요.

2. 타게팅과 예산 (남은 기간이 며칠뿐일 때)

  • 지역: 집결지(다문화도서관) 기준 반경 15~25km. 출신국·민족으로는 타게팅할 수 없으니 언어와 지역으로 좁힙니다.
  • 연령: 25~54세, 관심사: 육아·가족여행·캠핑.
  • 목표: 신청 링크가 있으면 트래픽/리드, 전화·카톡 접수면 메시지 캠페인.
  • 기간이 짧아 학습이 끝나기 어렵습니다. 광고 수는 적게, 예산은 마감 전 3~4일에 몰아서 쓰세요.

3. 캐러셀 순서와 규격

  1. 표지: 한 장만 보여도 "자녀 무료·성인 3만원"이 보이게.
  2. 1일차 오후: 소싸움 + 와인터널
  3. 숲체원: 저녁 레크·퀴즈(상품)·강연·숙박·숲체험
  4. 2일차: 새마을기념관 + 전체 일정 요약
  5. 사전접수 이벤트: 가격 비교 + 신청 방법

1080×1350(4:5). 핵심 글자는 가운데 1080×1080 안에 두어 1:1로 잘려도 읽힙니다. 스토리(9:16) 지면은 표지 한 장을 단일 이미지로 쓰는 편이 낫습니다.

4. 사진과 심사 주의점

  • 사진 출처 추천: 한국관광공사 포토코리아(photo.visitkorea.or.kr), 공공누리 제1유형이라 출처만 쓰면 광고에도 쓸 수 있습니다. 각 사진의 이용조건은 다운로드할 때 한 번 더 확인하세요.
  • 국립청도숲체원 사진은 기관(054-370-8500)에 사용 허락을 받거나 직접 찍은 사진을 쓰세요.
  • 소싸움은 소가 맞붙는 장면을 크게 쓰면 Meta 심사에서 폭력·동물 관련으로 걸리거나 거부감을 줄 수 있습니다. 경기장 전경이나 관중석 사진을 권합니다.
  • 번역은 광고비를 쓰기 전에 해당 언어 원어민(센터 통번역사 등)에게 한 번 검수받으세요.
